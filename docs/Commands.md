# Common Commands

## Run Commands
- starting dev server
    1. if in the (venv) deactivate
    2. cd coq-web
    3. npm run dev
    4. find at http://localhost:3000 (final)
        http://localhost:3000/practice (practice -current working page)
    
- starting python flask server
    1. if not in (venv) venv/Scripts/Activate.ps1
    2. cd coq-api/test
    3. python test-api.py
    find at http://127.0.0.1:8080

- activate and deactivate venv (virtual environment)
    - venv/Scripts/Activate.ps1
    - deavtivate

- ending servers
    1. ctrl + c

- clearing the terminal (visually cleans up everything)
    1. clear

- how to use "cd" (change directory)
    - you move through the directory linearly, so to move forward you say cd and then the name of the directories that you want to work up to
    - to move back you would say cd and the ../ to go back. so if you want to move to parent directories back it would be cd ../..
